# Contributing

Thanks for helping improve SORA Frame.

1. Fork the repo and create a branch from `main`.
2. Run `npm test` before opening a pull request.
3. Keep pull requests focused on one change.

## Sign your commits (DCO)

This project uses the [Developer Certificate of Origin](https://developercertificate.org/).
Add a `Signed-off-by` line to every commit to confirm you wrote the change or have the right to submit it:

```bash
git commit -s -m "fix: describe the change"
```
